# Aside용 운영 MCP 스모크 테스트 프롬프트

아래 내용을 Aside에 전달합니다. 이 프롬프트에는 API 키나 사용자 PIN을 포함하지 않습니다.

```text
보험 청구 도우미의 운영 연결을 안전하게 스모크 테스트해 주세요.

1. 다음 원격 MCP 서버가 이미 연결되어 있는지 확인하세요.
   이름: insurance-claim
   URL: https://insurance-claim-mcp-878600435547.asia-northeast3.run.app/mcp
   전송: Streamable HTTP
   인증: 서버 운영자가 Aside의 보호된 MCP 헤더 설정에 등록한 X-API-Key 사용.
   키를 대화에 요청하거나 출력하지 말고, 프롬프트/로그/웹 페이지에 복사하지 마세요.
2. 연결되어 있으면 읽기 전용 도구 list_standard_rules를 한 번 호출하세요.
   반환된 규칙 개수와 verified 상태 요약만 보고하고, 사용자 보험 정보는 조회하지 마세요.
3. 다음 작업은 하지 마세요: 사용자 조회/가입, 보험·특약 등록/수정/삭제, 청구 평가,
   운영 데이터 변경, 사용자 PIN이나 실제 보험 서류 요청.
4. MCP가 등록되지 않았거나 인증 실패하면 거기서 멈추고, Aside 설정 화면에서 운영자가
   서버 헤더를 안전하게 등록해야 한다고 보고하세요. 인증키를 대화로 요구하지 마세요.
5. 결과에는 성공/실패, 사용한 도구명, 규칙 개수 및 검증 여부 요약만 포함하고,
   키·PIN·개인정보는 출력하지 마세요.
```

## Aside 연결 사전 조건

- Aside에서 원격 MCP(Streamable HTTP) 서버 연결을 지원해야 합니다.
- 운영자가 Aside의 비밀/헤더 설정에 `X-API-Key`를 등록해야 합니다. 키를 프롬프트에 붙여넣지 않습니다.
- 이 테스트는 `list_standard_rules`만 호출하므로 사용자 계정이나 운영 보험 데이터를 변경하지 않습니다.
- 서비스 소개는 이 문서와 MCP 클라이언트 연결 가이드에서 확인합니다. 공개 소개 웹 페이지는 제공하지 않습니다.
