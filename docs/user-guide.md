# insurance-claim-mcp 이용 가이드

병원 영수증·약봉투와 가입한 보험 약관을 대조해 **예상 보험금**을 안내하는 AI 보험 비서 서비스의 이용 방법입니다.

> 이 서비스가 알려주는 금액은 **정보 제공용 예상치**입니다. 실제 지급 여부와 금액은 보험사 심사에 따라 달라지며, 이 서비스는 지급을 확정하거나 권유하지 않습니다.

## 1. 서비스 소개

- **하는 일**: 내 보험 정보를 저장해 두고, 병원에서 받은 영수증·처방전·약봉투를 보여주면 **어떤 보험에서 얼마 정도 나올지** 예상액을 계산해 안내합니다.
- **사용 방식**: 별도 앱이나 화면이 없습니다. **AI 비서(ChatGPT, Claude, Cline 등)와 대화만으로** 사용합니다. 대화에서 "보험비서 시작"이라고 말하면 안내가 시작됩니다.
- **정확도 원칙**: 약관 원문으로 검증되지 않은 항목이나 출처가 확인되지 않은 진료는 **추측으로 계산하지 않고** 결과에서 투명하게 표시합니다.

## 2. 역할 구분

| 역할 | 할 일 | 대상 문서 |
|---|---|---|
| **최종 사용자** | AI 비서와 대화하며 보험 등록·예상 보험금 조회 | 3장 |
| **설정자** | AI 클라이언트에 이 서비스(MCP)를 연결 | 4장 |
| **운영자** | 사용자별 인증 키 발급·폐기 | 4장 |

---

## 3. 최종 사용자 가이드

### 3-1 시작하기

AI 비서에게 **"보험비서 시작"** 이라고 말하세요. 이후 안내가 한국어로 진행됩니다.

사용 전에 준비하면 좋은 자료:

| 준비물 | 예시 |
|---|---|
| **보험 정보** | 보험증권(가입증서), 보험사 공식 앱의 계약 상세 화면, [한국신용정보원 본인신용정보 열람서비스(credit4u.or.kr)](https://www.credit4u.or.kr)의 보험신용정보 상세내역 |
| **진료 정보** | 진료비 계산서·영수증, 진료비 세부내역서(급여/비급여), 처방전(환자보관용), 약봉투 |

### 3-2 계정 (별명과 PIN)

- AI가 사용할 **별명(user_id)** 과 본인 확인용 **PIN(4~32자)** 을 정합니다.
- 별명은 영문·숫자·`_`·`-`만 사용할 수 있습니다.
- PIN은 서버에 해시로만 저장되며, 같은 별명을 쓰려는 다른 사람의 접근을 막는 역할을 합니다.
- **PIN을 대화·로그·메모에 남기면 안 됩니다** — AI가 요청하는 입력란에만 입력하세요.

### 3-3 보험 등록

1. AI가 **보험사, 상품명, 가입연도, 실손보험 세대, 특약명(담보명), 가입금액**을 읽기 위한 정보를 요청합니다.
2. 다음 중 한 가지 방법으로 정보를 제공하세요:
   - 보험증권(가입증서) 사진/PDF
   - 보험사 공식 앱·홈페이지에 본인 로그인 후 **계약 상세** 화면
   - credit4u.or.kr > 보험신용정보 > 정액형·실손형보험 > 상세내역
3. 증권에서 읽은 정보는 **"증권 근거"** 로, 증권이 아닌 자료(말로만 한 내용, 가공된 리포트 등)에서 읽은 정보는 **"사용자 진술"** 로 구분됩니다.
   - **증권 근거** 정보만 예상 보험금 계산에 사용되고, 사용자 진술만으로는 계산되지 않을 수 있습니다.
4. 등록 후 **확인이 필요한 특약**이 있으면 AI가 다시 물어봅니다. 증권을 다시 확인하고 답해 주세요.

> **개인정보 주의**: 보험증권을 올릴 때 **이름·주민등록번호·증권번호·계좌번호는 가려서** 올려 주세요. AI가 그런 정보를 요구하지 않습니다.

### 3-4 청구 예상액 계산

병원에서 받은 영수증·처방전·약봉투를 보여주세요. AI가 **급여/비급여 금액, 병원 종별, 질병코드(KCD), 처치명, 처방약**을 읽어 예상 보험금을 계산합니다.

- 실손보험은 **입원/통원 여부**와 **의료기관 유형(의원·병원·종합병원)** 이 결과에 영향을 줍니다. 영수증에 있으면 함께 확인해 주세요.
- 입력한 진료 정보는 서버에 저장되지 않고 계산에만 사용됩니다.

### 3-5 결과 읽는 법

| 표시 | 의미 |
|---|---|
| **지급 대상** | 이 진료가 담보 요건에 해당해 예상 금액을 계산했습니다. |
| **보장 제외** | 이 진료가 약관상 보장 제외 대상으로 판정되었습니다. (예: 치아파절) |
| **계산 보류** | 정보가 부족하거나(예: 세대 미확인, 질병코드 없음) **약관 원문 검증이 끝나지 않아** 계산하지 않았습니다. |

- 현재 모든 약관 수치는 **약관 원문과의 검증이 완료되지 않은 상태**이므로 결과는 어디까지나 **예상치**입니다.
- "지급 확정", "반드시 청구하세요" 같은 단정·권유 표현은 이 서비스가 사용하지 않으며, 확정 금액이 아님에 유의하세요.

## 4. 설정자·운영자 가이드

이 서비스는 **MCP(Model Context Protocol)** 로 제공됩니다. AI 클라이언트에 연결하려면 **사용자별 인증 키**가 필요합니다.

### 4-1 사용자별 키 발급 (운영자)

키는 **운영자 전용 CLI**로만 발급할 수 있습니다. 저장소 루트에서 프로젝트 가상환경으로 실행합니다.

```powershell
# 로컬 DB(SQLite) 대상
.\.venv\Scripts\python.exe scripts\manage_user_keys.py issue --user-id <별명>

# 운영 DB(Neon 등) 대상
$env:DATABASE_URL = "postgresql+psycopg://..."   # 운영 DB URL
.\.venv\Scripts\python.exe scripts\manage_user_keys.py issue --user-id <별명>
```

출력 예시:

```
사용자 'my_alias'에게 키를 발급했습니다 (key_id: ...)
새 키 (이번에만 표시; 안전한 비밀 전달 경로로 보내세요):
<raw_key>
서버에는 SHA-256 해시만 저장됩니다.
```

- **키 원문은 발급 시 한 번만 출력**됩니다. 다시 조회할 수 없으므로 즉시 안전한 경로로 소유자에게 전달하세요.
- 키 발급 전에 사용자가 먼저 등록되어 있어야 합니다(없으면 MCP `register_user`로 등록).
- 발급받은 키는 만료되지 않으므로, 사용하지 않게 되면 폐기하세요.

### 4-2 키 목록·폐기

```powershell
# 목록 (key_id·접두어·상태만 표시, 원문·해시는 노출 안 함)
.\.venv\Scripts\python.exe scripts\manage_user_keys.py list --user-id <별명>

# 폐기 (즉시 무효화, 되돌릴 수 없음)
.\.venv\Scripts\python.exe scripts\manage_user_keys.py revoke --user-id <별명> --key-id <key_id>
```

### 4-3 AI 클라이언트 연결 (MCP 설정)

원격 Streamable HTTP 연결 설정 예시입니다.

```json
{
  "mcpServers": {
    "insurance-claim": {
      "url": "https://insurance-claim-mcp-<프로젝트>.asia-northeast3.run.app/mcp",
      "type": "streamableHttp",
      "headers": {
        "X-User-Key": "<발급받은 키>",
        "X-User-Id": "<사용자 별명>"
      }
    }
  }
}
```

- `X-User-Key`(또는 `Authorization: Bearer`)로 인증하며, 성공하면 해당 계정의 PIN 입력을 대체합니다.
- `X-User-Id`는 권장 선택이며, 키 소유자와 다른 별명을 보내면 요청이 거부됩니다.
- PIN이 필요한 환경에서 PIN은 설정 파일·헤더에 저장하지 말고 **도구 호출 입력에만** 넣으세요.

로컬 stdio 연결·상세 설정은 [MCP 클라이언트 연결 가이드](mcp-client-setup.md)를 참고하세요.

### 4-4 보안 주의

- **키 원문**·**PIN**·**주민등록번호**·**증권번호**·**계좌번호**를 대화, 로그, 소스 코드, 공개 문서에 넣지 마세요.
- 키는 소유자 본인만 사용해야 하며, 계정이 공유되는 환경에서 공유 금지입니다.
